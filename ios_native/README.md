# SMART App (Native iOS - SwiftUI)

Modul aplikasi iOS Native dibina menggunakan **Swift** dan **SwiftUI** di dalam Xcode.

## Panduan Membuka / Pembangunan:
1. Buka **Xcode** di macOS.
2. Buka projek `SMARTApp.xcodeproj` di dalam folder ini.
3. Pilih iOS Simulator (contohnya iPhone 15 / 16) dan tekan **Run** (`⌘R`).
